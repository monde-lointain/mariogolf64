> Note: every `bss` entry in `mariogolf64.yaml` is raw, and no source file uses `section(".bss")` yet, so the `.bss` forms below are untested here. KMC GCC behavior is in [data and jump tables](/reference/kmc-gcc/data-and-jump-tables.md); check the forms on the first split against [editing rules](/reference/kmc-gcc/editing-rules.md).

Reproduce the original VRAM layout exactly. A local compile is not enough; the full ROM checksum must match. `symbol_addrs.txt` is the layout source; code references give types and sizes; expected VRAM addresses decide ordering, padding, arrays and boundaries.

# Workflow

1. **Identify the target range.** Find the target symbols in `symbol_addrs.txt`, note the first symbol, each following address, and the first symbol after the file's range. Check `mariogolf64.yaml` for the unsplit `bss` segment covering it.

2. **Split `mariogolf64.yaml`.** Split the unsplit raw `bss` range at the C file's first VRAM. Keep a trailing plain `bss` at the next unclaimed VRAM, and keep later `bss` entries at their original VRAMs. The owned `.bss` form is untested in this repo ([splat yaml](/reference/splat-yaml.md)):

   ```yaml
   - { type: .bss, vram: <first VRAM>, name: <dir>/<file> }
   - { start: <rom>, type: bss, vram: <next unclaimed VRAM> }
   ```

3. **Replace externs with definitions.** Convert only symbols in the target file's `.bss` range.
   * Give each definition `__attribute__((section(".bss")))` **and** an explicit zero initializer: `s32 foo __attribute__((section(".bss"))) = 0;`, `u8 buffer[0x10] __attribute__((section(".bss"))) = { 0 };`. Without both, KMC GCC does not keep the symbol in `.bss` in source order ([data and jump tables](/reference/kmc-gcc/data-and-jump-tables.md)).
   * Order definitions by expected VRAM, not by where the old externs appeared.
   * Use `static` only for file-local symbols nothing else references. Leave unrelated externs alone.

4. **Infer sizes** from address deltas and use sites.
   * Stacks: define the full array and pass `stack + sizeof(stack)` to `osCreateThread`.
   * `OSMesgQueue` buffers: size the array to the depth given to `osCreateMesgQueue`; pass the array base, not `&array`.
   * Unknown gaps: add a named or static padding array only when needed to keep the layout.
   * Prefer real structs and arrays over `u8 padding[]`. If a struct's size spans autogenerated labels, let the struct own that range.

5. **Fix renamed labels.** Moving symbols between files can change autogenerated names (`D_800D2930`, ...). Search the whole project for old names, update references, and never declare a symbol under both names.

6. **Build and compare layout.**

   ```bash
   ./tools/build-and-verify.sh
   mips-linux-gnu-nm -n build/mariogolf64.elf
   ```

   Compare the `nm` addresses to `symbol_addrs.txt`. If one symbol is right and every later one is early or late, the preceding symbol's size is wrong. Symbols the linker reorders are tentative `.comm` definitions ([data and jump tables](/reference/kmc-gcc/data-and-jump-tables.md)). Re-check array lengths, alignment, struct size and padding before editing YAML addresses. [data-differ](/tools/data-differ.md) finds the first mismatching symbol.

7. **Finish** only when `./tools/build-and-verify.sh` prints `build/mariogolf64.z64: OK`. Commit only the scoped YAML and source changes after it passes.

# Patterns

```c
OutputStruct_19E80 gCachedSpriteTextureEntry __attribute__((section(".bss"))) = { 0 };

OSMesgQueue displayQueue __attribute__((section(".bss"))) = { 0 };
OSMesg displayQueueMsgs[0x20] __attribute__((section(".bss"))) = { 0 };
osCreateMesgQueue(&displayQueue, displayQueueMsgs, 0x20);

OSThread audioThread __attribute__((section(".bss"))) = { 0 };
char audioThreadStack[0x180] __attribute__((section(".bss"))) = { 0 };
osCreateThread(&audioThread, 9, audioThreadEntry, 0, audioThreadStack + sizeof(audioThreadStack), 7);
```

# Quality

No pointer arithmetic to fake fields; no `void *` where usage reveals a type; keep the [file structure](/project/code-quality.md); search `src/` and `include/` for stale or duplicate declarations before the final verify. A generic compiler lesson belongs in the [KMC GCC reference](/reference/kmc-gcc/editing-rules.md).
