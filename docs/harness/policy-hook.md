`.omp/hooks/pre/mg64-policy.ts` returns a block reason for each tool call it matches. omp loads hooks from `<session cwd>/.omp/hooks/pre/`; decomp environments reach it through their `.omp` symlink, and the repo root comes from the file's real path. A running session keeps the hook it loaded, so start a new session after editing it. Tests: `bun test ./.omp/hooks/tests/mg64-policy.test.ts`. A rule change is a [comparison change](/harness/changing-the-harness.md): a guarded action stays blocked.

# bash

Checks run in this order; the first match blocks. Regex rules apply per line; the `make` rule applies per shell segment.

| Blocked | Because |
|---|---|
| `git commit --no-verify`, case-insensitive, with `--no-verify` directly after `git commit` on one line | The pre-commit rebuild must run ([hook](/harness/git-hook-and-ci.md)). |
| `make` as a segment's command word (start of a line, or after `;`, `&` or `\|`), case-insensitive, unless its arguments are `[-s\|--no-print-directory] print-cflags [SRC=path]`. Redirections such as `2>&1` and `> out.txt` are removed first. | Use `./tools/build-and-verify.sh` or `./build.sh <file>`. The allowed form only prints flags. |
| `python3 -m splat split` (or `python`) at the start of a segment | The build scripts run Splat. |
| `ctx.c` anywhere, except where the word only names the file: a grep pattern (first non-option word, with no `-e`/`-f`), `--exclude[-dir]=<glob>`, rg `-g`/`--glob '!<glob>'`, find `! -name`/`-not -name`, or the value of `git commit -m`/`--message`. A `ctx.c` operand still blocks. | Generated decomp.me / m2c scratch. |
| `temp.c` anywhere in the command, with no exceptions | Generated scratch. |
| Mutating `asm/`: `tee`, `touch`, `truncate`, `rm`, `unlink`, `mv`, `cp`, `install`, `chmod`, `chown`, `sed -i`, `perl -…i` with an `asm/` argument in the same segment; `>` or `>>` to `asm/` or `./asm/`; `apply_patch` naming `asm/`; `git checkout`, `restore`, `clean` or `apply` naming `asm/`; a `python`, `python3`, `ruby` or `node` `-c`/`-e` line with `asm/` before a write verb (`write`, `unlink`, `remove`, `rename`, `replace`, `open(…,'w')`) | `asm/` is generated by Splat. |
| Writes into `tools/gcc_kmc`, `tools/kmc-cc`, `tools/decomp-permuter` or `tools/asm-differ`: `tee`, `sed -i`, `perl -…i`, `apply_patch`, `rm`, `mv`, `cp`, `chmod`, `git checkout` or `git restore` in the same segment, or a redirect whose target names one | Vendored toolchain and submodules are [protected](/project/ground-rules.md#2-protected-paths). Use a Makefile profile override instead. |
| A permuter run without a valid `timeout`, or whose timeout would end less than 120 s before `NIGEL_TIMEOUT_DEADLINE_UNIX` (see below) | Runs are unbounded otherwise. A permuter path that is an argument of a read-only command (`cat`, `diff`, `file`, `git`, `grep`, `head`, `less`, `ls`, `readlink`, `realpath`, `rg`, `sed`, `stat`, `tail`, `wc`) is not a run. |

## Permuter timeout

A permuter run is a command word `tools/permuter` or `tools/decomp-permuter/permuter.py`, optionally behind a path (`./`, `../mg64-a/`, an absolute path).

* `timeout` must be the command word of its segment, after any `NAME=value` assignments. `--foreground`, `--preserve-status` and `-v` are skipped, and `-k`, `-s`, `--kill-after` and `--signal` are skipped with their argument. The duration is a positive number with an optional `s`, `m`, `h` or `d` suffix. `0` and `infinity` are not durations.
* `NIGEL_TIMEOUT_DEADLINE_UNIX` is read from the hook's own process environment, not from the command. Unset or empty means no deadline. Otherwise it must be an integer. The run is blocked when `now + timeout > deadline - 120`.
* A command that mentions `permuter` and does not tokenize (unterminated quote or trailing backslash) is blocked. Commands that never mention it are not tokenized, so heredocs with unbalanced apostrophes pass.

# read, write, edit, ast_edit

* `read` (`path`, `_path`): blocked when the path, or any prefix left after stripping `:selector` suffixes, ends in `ctx.c` or `temp.c`. `read sha1` and `read ctx.c.bak:1-3` pass; `read ctx.c:1-3` is blocked.
* `write` (`path`, `_path`), `edit` (`path`, `_path`, `paths`, and the patch text in `input`), and `ast_edit` (`path` and `paths` entries): blocked when the target ends in `ctx.c`, `temp.c` or `mariogolf64.sha1`, when a repo-relative path has a component named `asm`, or when it is under a vendored path.
* `write xd://ast_edit` parses its `content` as JSON and checks each `path` and `paths` entry; invalid JSON is blocked.
* `edit` patch text: hashline `[PATH#TAG]` and legacy `¶PATH` headers, `MV DEST`, `*** Add|Update|Delete File:` and `*** Move to:`.
* Paths expand `~`, resolve against the call's cwd, and follow symlinks where they exist. Paths outside the repo and `scheme://` URLs get only the suffix rules.
* `ast_edit` globs are checked by their literal prefix and as a whole pattern.

# Known limits

Gaps: calls the hook allows, though the rule intends to block them.

* `--no-verify` is matched only directly after `git commit`. `git commit -n`, `git commit -m x --no-verify`, `git -c k=v commit --no-verify` and `git commit --amend --no-verify` pass.
* `make` is recognized only as a segment's command word. `(make`, `xargs make`, `time make`, `FOO=1 make` and `bash -c 'make'` pass.
* `asm/` redirects are matched on the bare target: `echo x > "asm/x.s"` passes. `python3 -c "open('asm/x.s','w')"` passes because the `asm/` text must come before the write verb.
* `permuter` is recognized only as the command words above. `./permuter` from inside `tools/` passes.
* Bash heuristics do not use the call's `cwd`. Read-only tools (`grep`, `glob`) are not policed. The `eval` tool's `tool.bash()` bridge emits no `tool_call`, so it is not policed.
* `ast_edit` globs are not expanded: braces or wildcards before the first `/` are checked as literal text.

False positives: calls the hook blocks, though the rule does not intend to.

* `grep "x\|ctx.c" src/x.c` is blocked: a backslash inside double quotes defeats the grep-pattern exclusion. Single quotes pass.
* A quoted `|make` is blocked, for example `grep 'a\|make x' file.c`. The rule does not understand quotes.
* `temp.c` is blocked anywhere in a command, including `git log -- temp.c`.
* Suffix rules are plain `endsWith`, so `attemp.c` and `src/foo_ctx.c` are blocked.
