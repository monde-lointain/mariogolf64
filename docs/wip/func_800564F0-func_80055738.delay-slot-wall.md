# func_800564F0 + func_80055738 — banked non-void fall-through guards

## Resolution (2026-10-15)

Declaring each function `s32` and falling off its end, without an explicit
`return`, preserves the ROM's empty null-guard delay slot without adding
return-value instructions. The result must not be consumed. There are no
committed C callers or separate declarations to migrate.
