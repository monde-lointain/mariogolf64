## What matched byte-exact (levers applied)

- **Single callee-saved reg for club+entry.** Read `kind` AFTER the
  `get_table_entry` call so `club`'s live range spans it (-> `$s0`), then `$s0`
  reuses to `entry`. Reading kind before the call cost a second saved reg (`$s1`)
  and flipped `lh`->`lhu`. (Same shape as `docs/levers.md` (cross call live range callee saved lever).)
- **Club index math**: `*(s16*)(D_801B7222 + D_80250B54*0xB8 + D_80250B40*2)` with
  `extern u8 D_801B7222[]` reproduces the base-first `*184` synthesis + `j*2` add.
- **kind==0 arm**: exact, including the shared `func_80216CAC()` after the if/else
  and the `id==0x16 ? 0x50 : 0x52` two-arm.

## Residual (three coins, same wall class, none source-flippable together)

1. **`&&` guard chain -> branch-likely.** ROM fills the plain `beqz/bnez` delay
   slots with `a0=1`/`a0=2`; every source form (flat `a=2; if(A&&B&&C) a=1;`,
   nested if, ternary) emits `beqzl/bnezl` (annulled) instead.
2. **Terminal `id==8 ? 0x56 : 0x54` -> branchless select.** gcc if-converts to
   `xori/sltiu/negu/andi/ori`; ROM keeps `bne v1,8` + two `li a0`. A `goto` to a
   shared `snd:` label does NOT stop the merge (jump-opt rejoins the arms).
   `#value-select-if-else-vs-branch-likely` / `docs/levers.md` (store flag single bit terminal wall).
3. **`a0=0x54` delay-slot sharing.** ROM sets `a0=0x54` once (in the `id<2`
   branch delay) and shares it across the `id<2`, `id==2` and default arms via
   fall/branch-through. An if-chain re-materialises `0x54` each arm; a `switch`
   lowers 6 instr SHORTER (clusters `{0,1,2}` to a range test).
