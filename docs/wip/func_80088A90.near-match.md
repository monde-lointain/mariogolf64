# func_80088A90 near-match (S254 carry)

Main-segment glyph/units-string display-list emitter in `src/main/func_80080220.c`
(0x14C / 332B). Renders a numeric measurement string into a hand-rolled per-char
6-word `G_TEXRECT` block. S243 raw-DL-word wall class (kin to func_80071370.c's
73F24 / 74230 / 74500, all carried).

## Behavior (fully RE'd)
Args: `(u32** holder, s32 x, s32 row, u8* str)`.
- `dl = *holder`; per non-space char emits 6 DL words, `dl += 0x18`, then
  `*holder = dl` on exit.
- Precomputed word templates: `word_hi = (((row+0xC)<<2)&0xFFF) | 0xE4000000`
  (G_TEXRECT), `word_lo = (row<<2)&0xFFF`, plus consts 0xE1000000, 0xF1000000,
  0x04000400.
- Per char: `new_x = x + width`; write
  - `p[-1] = (((new_x<<2)&0xFFF)<<12) | word_hi`
  - `p[0]  = (((x<<2)&0xFFF)<<12) | word_lo`  (cursor += 8 each pair)
  - `0xE1000000`, `tile<<21`
  - `0xF1000000`, `0x04000400`
  - `x = new_x`.
- Glyph map: `'f'`->tile 0x60 width 0x10; `'.'`->0x70 w4; `'m'`->0x50 w8;
  `'y'`->0x58 w8; digit->`(c-0x30)*8` w8; `' '`-> skip (advance str only, no DL).

## Near-match C (structurally complete; emit block byte-identical in isolation)
```c
void func_80088A90(u32** holder, s32 x, s32 row, u8* str) {
  u32* dl = *holder;
  u32* p;
  s32 ch, tile, advance, new_x;
  u32 word_hi = (((row + 0xC) << 2) & 0xFFF) | 0xE4000000;
  s32 word_lo = (row << 2) & 0xFFF;

  ch = *str;
  if (ch == 0) goto end;
  p = dl - 1;
  ch = *str & 0xFF;
  do {
    if (ch == 0x66) { advance = 0x10; tile = 0x60; goto emit; }
    if (ch < 0x67) {
      if (ch == 0x20) { str++; goto next; }
      advance = 0x4;
      if (ch == 0x2E) { tile = 0x70; goto emit; }
      goto digit;
    }
    advance = 0x8;
    if (ch == 0x6D) { tile = 0x50; goto emit; }
    if (ch == 0x79) { tile = 0x58; goto emit; }
  digit:
    ch = *str; advance = 0x8; tile = (ch - 0x30) << 3;
  emit:
    p += 2; new_x = x + advance;
    p[-1] = (((new_x << 2) & 0xFFF) << 12) | word_hi;
    p[0]  = (((x << 2) & 0xFFF) << 12) | word_lo;
    p += 2; p[-1] = 0xE1000000; p[0] = tile << 21;
    p += 2; dl += 6; x = new_x;
    p[-1] = 0xF1000000; p[0] = 0x04000400;
    str++;
  next:
    ch = *str & 0xFF;
  } while (ch != 0);
end:
  *holder = dl;
}
```

## Terminal divergence (permuter-class, not source-leverable)
1. **Char-mask register split.** ROM keeps the raw `lbu` byte in `t0` for the
   `bnez t0` loop test AND a redundant masked copy `andi v1,t0,0xFF` in a
   separate reg for the `beq`/`slti` classification. My build collapses both into
   one reg, which cascades the entire allocation: ROM `dl=t1 / cursor=a2 /
   word_lo=t3`; mine `dl=t2 / cursor=t1 / word_lo=a2`. Every faithful spelling of
   the u8 char (`u8`, `s32 & 0xFF`, cast) either collapses or double-masks.
2. **reorg branch-likely toward later handlers.** ROM classifies with `beq`/
   `beql` that branch TOWARD physically-later handler labels; the space-skip
   (`beql v1,0x20`), 'm' (`beql v1,0x6D`), and '.' set their advance/width in the
   ANNULLED delay slot (reorg.c optimize_skip, single-insn conditional). A
   structured if-else emits `bne`-past + `nop`; the branch-likely form is not
   reproducible from faithful C.

Both are the same terminal class as the S243 raw-DL-word family (regalloc +
reorg schedule coin). Not permuter-reachable in project history for this class.
