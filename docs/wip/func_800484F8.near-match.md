## What it does
Called when (re)starting a game state. Sets HUD/flag globals
(`D_801061CE=1`, `D_801061B8=-1`, `D_801061C0=1`, `D_801061C3=1`, `D_801B7F70=0`,
`putting_meter_level=0`, `D_800BE694=0`, `D_801B5530=D_801B5580=45.0f`), then:
- if `rumble_disable_flag != 0`: `play_bgm_by_id(0x1F, 0x11)`.
- else `switch (D_801B608C)` (12-entry `jtbl_800CC818`, indices 0/1/6/8 →
  default) picks a bgm id: case3→0x1A, case2/4→`func_8005244C(0,1)?0x14:0x19`,
  case10→`func_80052220()==D_801B6098?0x14:0x2E`, case5→0xB, case7→0x18,
  case9→`play_bgm_by_id(0x1D,1)` + clear D_801061C0/C3 + return, case11→…0x2B,
  default→`func_80052220()`+D_801B6098/D_801B6090/g_terrain logic → 0x14/0x1B/0x2D.
  Then `play_bgm_by_id(bgm, 1)`.

To reproduce the ROM's 0-based 12-entry jump table (not a `x-2` normalised
10-entry one), the switch needs explicit `case 0:`/`case 1:` folded into
`default` so gcc's min case value is 0. Case bodies emit in source order, so
order them by ascending target address (3, 2/4, 10, 5, 7, 9, 11, default-last).

## The wall
Default block `if (func_80052220()==D_801B6098 && D_801B6090!=1) bgm=0x14; else
bgm=(g_terrain!=0?0x2D:0x1B)`: the ROM keeps the second test as plain
`beq D_801B6090,1,else; nop; j tail; li a0,0x14`; every C spelling (`&&`, negated
`||`, explicit `goto elseblk`) makes gcc-2.7.2's reorg branch-likely it to
`bnel …,tail; li …,0x14(annulled)` — 3 instructions shorter. Confirmed goto-proof
(matches the S262 func_80046604 finding + `docs/levers.md` (store flag single bit terminal wall)).

Separately, `bgm` is held in `a2` (needs `move a0,a2` at the tail-call) where the
ROM sets `a0` directly in each case (`#call-result-a0-vs-v0`): a0 is busy as the
call-arg register in the switch (`func_8005244C(0,1)`, case-9's direct call), so
gcc's allocator avoids a0 for the cross-case value. The two residuals are coupled:
the a0/a2 choice feeds the branch-likely layout.

Not permuter-eligible: the branch-likely is a count/branch-target residual the
permuter is blind to and cannot reach (goto-proof; source-invariant). Banking
would also need the `jtbl_800CC818` rodata carved from the shared A7990 blob.
