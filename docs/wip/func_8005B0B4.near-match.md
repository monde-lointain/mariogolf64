## Two fixes already found
1. **`lb` for val**: `s32 val = ((s8*)arg0)[0x2C]` (not `s8 val = *(s8*)`) — the s8
   local was loaded `lbu` then re-`sll24/sra24` sign-extended at each signed use

## S268 re-open with the S260 out-of-line-handler lever — PARTIAL, residual re-classed

put the accumulator in `a1` (ROM: `v1`) and filled the first branch delay slot with
`v1=0` instead of `sel=flags&0xF`. Three S260/structural levers fixed those sub-issues:

Result: score 4965→4165, structure now matches ROM on accumulator role, the sel

## Residual (terminal, S268) = 3-register global.c allocno permutation
The sole remaining divergence is a register-role PERMUTATION on the three loaded values:
- ROM: flags→`a2`, val→`a0` (reuses the dead arg0 reg), sel→`a1`.
- Mine: flags→`a1`, val→`a2`, sel→`a0`.
This is a `global.c` allocno free-register seed (which of a0/a1/a2 the first load claims),

identical — gcc re-canonicalizes the load order and the seed is unchanged. Plus the

one-value handler, though it DID for c3). asm-differ scores the 3-reg cascade at

plateaus on multi-register permutations; this is a 3-reg permute).
