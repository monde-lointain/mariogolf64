# func_80029C00 — FCSR mask intrinsic (TERMINAL, hasm candidate)

**Status:** not standalone-bankable from C. Carried indefinitely; do NOT re-commit as a fresh leaf.

## Body (0x34, 13 instr, leaf, 0 jal)
Reads the FP control/status register, masks bits, writes it back:

```
cfc1  $a0, $31
lui/ori $a1, 0x0FFFE0FF
and   $a0, $a0, $a1
addiu $a1, $zero, -0xF81      ; 0xFFFFF07F
and   $a0, $a0, $a1
addiu $a1, $zero, 0x0
or    $a0, $a0, $a1
ctc1  $a0, $31
jr    $ra
```

Clears FP enable/cause/flag bits in FCSR ($31). Equivalent libultra idiom
(`__osSetFpsr`/`osGetFpsr` style) uses `cfc1`/`ctc1 $31`, which **gcc 2.7.2 emits no
plain-C form for** — there is no builtin/intrinsic that produces `cfc1/ctc1 $31` in the
KMC o32 toolchain. Any C body needs inline asm; that is a `hasm` decision, not a match.
