# func_8002BE78 - GCC nested function of draw_ground_shadow_decals (carry, not a wall)

**Verdict: CARRY, coupled.** Not lever-crackable standalone; banks as a nested function INSIDE its
decompiled parent `draw_ground_shadow_decals` (still asm this sprint, 3724B, S269 OUT list). Per
[[nested-function-banks-the-parent-too]] / `docs/hazards.md#nested-function-static-chain-spill`.

## Evidence
- Arg arrives in `$v0`, not `$a0` (non-ABI). Prologue: `addiu sp,-8; addu a0,v0,zero; sw v0,0(sp)`
  (the `sw v0,0(sp)` is a dead spill; `$v0` = `STATIC_CHAIN_REGNUM` = `$2`, mips.h:1310).
- Single caller `draw_ground_shadow_decals @ 8002BFD4` sets the chain in the delay slot:
  `jal func_8002BE78; addiu $v0,$sp,0x10` = address of a parent stack local (sp+0x10..0x1C).
- Child is emitted BEFORE the parent (0x8002BE78 < 0x8002BF1C) = gcc nested-child ordering.
- Body reads parent local field0 (sp+0x10), writes fields 4/8/C (sp+0x14/0x18/0x1C): the parent
  fills field0 at the call site, the child derives 4/8/C.

## Semantics (for the parent decomp)
Struct `S { s32 f0; s32 f4; s32 f8; s32 fC; }` at parent sp+0x10. Nested child does, on `S *p`:
```
if (p->f0 < 0) p->f4 = 0; else p->f4 = p->f0;   // clamp low to 0 (bgezl annul)
if (p->f0 > 0) p->f8 = 0; else p->f8 = (-p->f0) / 7;   // magic 0x92492493 = /7
if (p->f4 > 0) p->fC = (0xE0 - p->f4) / 7; else p->fC = 0x20 - p->f8;
```
(0x92492493 signed-divide-by-7 magic; `mult; mfhi; addu; sra 2; sra 31; subu` is gcc's /7 idiom.)

## Re-open when
`draw_ground_shadow_decals` is decompiled. Write this as a nested `static` function (or GCC nested
fn) lexically inside the parent so gcc homes the static chain in `$v0`; bank both together.
