## Levers (for the bundle sprint)
1. Bare `guRandom()` at loop top — result discarded; keep the call statement.
2. SDK `RAND(x)` (gu.h:45) is UNPARENTHESISED: `RAND(spawned*3)` = `(rand%spawned)*3`. Use explicit
   `guRandom() % (spawned * 3)`. `RAND(32)` is fine.
3. `if (spawned*3 != 0) {...} else { speed = 5*3*512; }` — the `beql;li 0x1E00` is NOT a wall; reorg
   pulls the 1-instr else into the annulled slot. All 4 branch-likely free (two `bltzl` = gcc signed-%32).
4. `verts[0..2]` re-loads the chain slot 3x (intervening `swc1` to `*p` invalidates cse MEM table) —
   spell naturally, do NOT cache a pointer.
5. mul.s chaining (binutils class-B oracle): unk_0C/unk_14 share the hoisted `$fs1`=0.03f/1024 const
   (adjacent `mul.s;nop;mul.s`); unk_10 uses a distinct 0.15f/1024 whose `li.s` lands between the muls
   (no class-B nop). Two of three products share the const, the middle differs — hard source-shape
   constraint.
