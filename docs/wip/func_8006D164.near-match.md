## Residual (the whole stores block + inner loop match)
ROM: outer counter `i`=t0, inner bound 7=t1 (hoisted to top: `move t0,zero; li t1,7`), src=a3, dst=a2,
outer bound `li v0,4` REMATERIALIZED inside the outer loop (v0 = the inner data reg, set-in-loop -> LICM
can't hoist it).
Build: src=t0, dst=a3, i=a2, 7=t1, **4 HOISTED to a separate t2** (a fresh reg not set in loop -> LICM
freely hoists). This frees no register, so the pointer bases rotate off a2/a3.

Root cause: LICM (loop.c move_movables) hoists the outer-loop invariant `4` in my build but not the
ROM's, because the ROM assigned `4` to v0 (the data reg, set-in-loop) so the hoist was blocked. The
hoist decision is coupled to the register allocation, which is coupled back to the hoist -> a 3-reg
rotation {src,dst,i}. Class: `docs/hazards.md#top-tested-loop-goto-local-hoist` "SELECTIVELY hoists" + [[loop-weight-
and-live-length-regalloc-steering]].
