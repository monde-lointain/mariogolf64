# `func_8008D3F4` decode (S301)

`src/main/func_8008D100.c`, 634 instructions, 0x9E8, frame -0x110. Sun / lens-flare emitter.
`Gfx**` parameter (not `glistp`), so every `gfx++` is register-only and gcc's scheduler hoists all
~30 pointer increments above their stores -- which is why the ROM spills about twenty `Gfx*` slots
and command words to the frame. That spill is a *consequence* of the local-pointer form, not
pressure to reproduce by hand.

## `.rodata` verdict (gate risk 1, cleared)

Every float constant is an inline `lui $at, 0x4180`-style immediate (16.0, 96.0, 120.0, 160.0,
224.0, 240.0, 304.0, 320.0, 360.0, 440.0, 8.0, 2^31, 1/128) plus `lwc1` loads of the game globals
`D_800C5F24`, `D_800C5F2C`, `D_800C691C`, `D_800C6928+`. **No pool constants, so the leaf emits no
`.rodata` of its own and the uncarved-host blocker does not apply.**
