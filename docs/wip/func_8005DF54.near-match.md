## Wall (terminal, non-source-leverable)

`jal flag_is_set` at 39374 clobbers `$a2` (caller-saved), and there is no `move s2,a2` / stack save of
a 3rd arg in the prologue, so the value cannot be an ABI-passed 3rd argument that survived the call —
it is read straight out of the INCOMING `$s2`.

@801F55EC) all set only `a0`/`a1` before the `jal`, never `$s2`/`$a2`. So func_8005DF54 consumes the
caller's live `$s2` register directly — a hand-rolled non-ABI calling convention (the game passes a
context through `$s2`), identical in class to the func_80041E8C `$v0`-arg wall

… asm("$s2")` is a -O2 no-op for reads; see [[signed-divide-const-v0v1-quotient-destination]]). No
