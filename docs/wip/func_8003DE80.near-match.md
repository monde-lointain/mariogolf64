## The function

`4*(centre!='0') + (up!='0') + (down!='0') + (left!='0') + (right!='0')`. The `!= 0x30` test
emits `xori`+`sltu` (matches). `row = 15 - cz`, `col = cx`; cell index `(row<<4)|col`.
