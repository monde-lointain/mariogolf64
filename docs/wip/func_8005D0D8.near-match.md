# func_8005D0D8 near-match (S264)

**File:** `src/main/func_80059BA0.c` (integer-glue/accessor pack). Size 0x10C (67 instr).
**Status:** CARRY. Structural body fully RE'd; mine 61/67. Residual = 2 gcc coins + a base-reg allocno.

## What it is
`func_8005AF50()` returns a `u8*` game-state base. 5 entries at `base + 0x1DF0 + i*0x68` (stride 0x68).
Loop A zeros a `s32 flags[5]` stack array. Loop B flags entry i (`flags[i]=1`) if ANY validation
fails: `(byte36 & 0x80) && ((byte36 & 0xF) out of [0,4])`, or `byte37 >= 0x12`, or `byte39 >= 4`, or
`byte34 >= 6`, or `byte35 >= 6`. Loop C toggles bit7 of byte36 (`^= 0x80`) on each flagged entry.

## Working source (structural match, ~61/67)
```c
void func_8005D0D8(void) {
  s32 flags[5];
  u8* base = func_8005AF50();
  s32 off, i, *fp;

  fp = flags; i = 0;
  do { *fp++ = 0; } while (++i != 5);            /* up-count pointer walk defeats loop.c biv reversal */

  off = 0x1DF0; i = 0;
  do {
    u8* p = base + off;
    s8 b = *(s8*)(p + 0x36);
    s32 lo = b;                                  /* two-def lo (=b then &=0xF): forces lb + delay-slot andi */
    if (b & 0x80) {
      lo &= 0xF;
      if (lo >= 5 || lo < 0) flags[i] = 1;       /* ROM: slti + bltzl (signed). mine: sltiu (coin, below) */
    }
    if (p[0x37] >= 0x12) flags[i] = 1;
    if (p[0x39] >= 4)    flags[i] = 1;
    if (p[0x34] >= 6)    flags[i] = 1;
    if (p[0x35] >= 6)    flags[i] = 1;
    off += 0x68;
  } while (++i != 5);

  off = 0x1DF0; i = 0;
  do {
    u8* p = base + off;                          /* p OUTSIDE the if: fills the bne delay slot (ROM style) */
    if (flags[i] == 1) p[0x36] ^= 0x80;
    off += 0x68;
  } while (++i != 5);
}
```

## Levers that landed (confirmed via objdump)
1. **Up-count pointer walk (`*fp++`, `++i != 5`)** for loop A -> ROM's `bne a1,v1` up-counter, not the
   loop.c-reversed down-counter a plain `for(i=0;i<5;i++)flags[i]=0` produces.
2. **Two-def `lo` (`s32 lo = b; ... lo &= 0xF;`)** -> ROM's `lb` (signed load, kept) + `move v1,v0` +
   the `andi v1,v1,0xF` in the beqz DELAY slot. A single-def `s32 lo = b & 0xF` reads `lbu` and inlines
   the andi.
3. **`p = base + off` OUTSIDE the loop-C `if`** -> the `p` compute (`addu v1,base,off`) fills the
   `bne flags[i]!=1` delay slot, matching ROM's plain `bne`+`addu` (not a `bnel`+increment).
4. Separate `off` var (not `flags[i]`/`base[i]` indexing) -> the running-offset register + base add.

## Residual (2 coins + allocno)
1. **bit7 `lo < 0` range-elimination coin (~2 instr).** ROM keeps `slti v1,5` (signed) + `bltzl v1`
   (the provably-dead `lo<0`, since `lo = b & 0xF` in [0,15]). My build proves `lo>=0` and folds to a
   single `sltiu v0,v1,5`, dropping the bltzl+sw. ROM's gcc did NOT narrow because the `andi 0xF`
   lands in the branch delay slot (post-combine reorg), so at combine time the compare saw a
   sign-ambiguous value and used the GLOBAL nonzero_bits (union incl. sign). Any source that masks
   `lo` before the compare gives combine LOCAL `nonzero_bits=0xF` (the `&=` last_set dominates the
   compare in-BB) -> narrows. No source form separates the mask from the compare by a BB boundary
   without changing the asm. Same class as the store-flag/value-select coins: source-invariant.
2. **xor-hoist coin (1 instr).** ROM hoists `li t0,-0x80` (0xFFFFFF80) out of loop C and uses `xor`
   (register). My `p[0x36] ^= 0x80` emits inline `xori 0x80`; `^= -0x80` folds back to `xori 0x80`
   (u8 store, gcc drops the high bits pre-loop-motion). ROM's full-width -0x80 gets hoisted as a
   loop-invariant reg-load; not reproducible while gcc simplifies the constant to fit `xori`.
3. **base-register allocno.** ROM base=`t1`, counter=`a1`, offset=`t0`; mine base=`t0`, counter=`a0`,
   offset=`a2`. global.c allocno-order coin cascading from the init loop; not source-steerable here.
