# func_80041EC0 + func_80041E8C — banked (2026-10-14)

Main segment, host `src/main/get_tile_attribute.c`, profile `main`.
Parent: ROM `0x1D2C0`, VRAM `0x80041EC0`, `0x368` bytes / 218 instructions.
Child: ROM `0x1D28C`, VRAM `0x80041E8C`, `0x34` bytes / 13 instructions.

## Resolution

The S218 custom-ABI diagnosis was incorrect. The helper's dead incoming
`sw v0,0(sp)` and both caller-side `addiu v0,sp,0x10` instructions are GCC's
static-chain convention, not a pointer argument. The helper reads only globals.
Defining `s32 selected_flag(void)` inside `func_80041EC0` reproduces the child
before its parent and both chain setups without inline assembly or register bindings:

```c
s32 selected_flag(void) {
  return ((D_800BB080 + D_800BB088) << 4) + D_800BB084;
}
```

The parent displays an eight-row, sixteen-column debug flag grid, normalizes its
cursor/page, and sets or clears the selected flag from the input buttons.

## Reproduction and verification

- Recovered the parent directly from assembly after m2c rejected the host's
  existing GNU nested function context.
- Standalone-call baseline: 218 instructions, score 10, only the two `a0` versus
  `v0` chain-setup instructions differ.
- Nested candidate: score 0, 218/218 parent rows; measurement
  `nonmatchings/func_80041EC0/measurements/d22c41e1ce128f4cd7e758bcbad3ed0e127abfd8e0a9a02af04e22696763073b.json`.
- Formatted the changed host range with `clang-format-23`, built the host with
  `tools/rom_build.py build --object src/main/get_tile_attribute.o`, and compared
  both function ranges against the isolated object: all 13 + 218 instructions,
  relocation targets, and normalized addends identical.
- `tools/verify-rom.sh` exited successfully:
  `CMake build OK + ROM SHA-1 MATCH (e2c4e7a905b29529b49a1619a401fe699224829b)`.

## Retained source-shape evidence

- Bind the display column into the inner header:
  `for (bit = 0, column = 6; bit < 16; bit++, column += 2)`.
  A separate outer assignment hoists the column initialization and changes call setup.
- Normalize the row with `while (1)` and one body-top cursor load followed by
  negative / at-least-eight / break branches.
- Cache `D_800FED18` for the navigation tests, but reread it for the final
  `0x8000` and `0x4000` set/clear tests.
