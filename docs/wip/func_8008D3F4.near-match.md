# `func_8008D3F4` decode (S301)

`src/main/func_8008D100.c`, 634 instructions, 0x9E8, frame -0x110. Sun / lens-flare emitter.
`Gfx**` parameter (not `glistp`), so every `gfx++` is register-only and gcc's scheduler hoists all
~30 pointer increments above their stores -- which is why the ROM spills about twenty `Gfx*` slots
and command words to the frame. That spill is a *consequence* of the local-pointer form, not
pressure to reproduce by hand.

## `.rodata` verdict (gate risk 1, cleared)

Every float constant is an inline `lui $at, 0x4180`-style immediate (16.0, 96.0, 120.0, 160.0,
224.0, 240.0, 304.0, 320.0, 360.0, 440.0, 8.0, 2^31, 1/128) plus `lwc1` loads of the game globals
`D_800C5F24`, `D_800C5F2C`, `D_800C691C`, `D_800C6928+`. **No pool constants, so the leaf emits no
`.rodata` of its own and the uncarved-host blocker does not apply.**

## Levers, measured (cmpfn diff lines)

| change | result |
| --- | --- |
| first build | 654, frame -0x130 |
| one `d = 0x10000 / w;` temp instead of two divides in the macro args | 632 |
| separate `px`/`py` locals instead of reusing `dx`/`dy` | 632 (no change) |
| **`extern f32 D_800C5F24[]` + `[0]` (and `D_800C5F2C`)** | **634/634, frame exact, 116** |
| move the `px`/`py` computation above the loop's `gDPPipeSync` | 76 |
| `q` temp to stop `fold` reassociating `(n<<8) + (base + off)` into `((n<<8) + base) + off` | 68 |
| `m = putter_mode_flag;` read as its own statement before the DL commands | 64 |
| **`do { gDPPipeSync(gfx++); } while (0);` on the 4th pre-guard command** | **24** |

The array-subscript lever is the decisive one and is the documented
`mem-in-struct-index-global-cse` / `aggregate-store-pins-pointer-load` mechanism: as plain scalars,
`D_800C5F24`/`D_800C5F2C` do not conflict with the `MEM_IN_STRUCT_P` stores through `Gfx *`, so
`loop.c` hoists both loads and `160.0f - x` / `96.0f - y` out of the loop and needs `$f20`/`$f22`
(hence the `sdc1` pair and the +0x20 frame). Subscripting them makes the loads conflict with the
`Gfx` stores, so they are re-read every iteration exactly as the ROM does.

The final lever came from the permuter, which is the pattern the loop docs describe: base score
1025, best candidate 460, and its whole source diff was a `do { … } while (0)` around one
`_g->words.w1 = 0;` -- the fourth pre-guard `gDPPipeSync`. Wrapping that one macro call at source
level took 64 to 24. Note the permuter needed the nested-function workaround: `import.py` aborts on
`emit_snapshot_spiral_wipe_dl`, so the import was run against a copy of the TU with that function
deleted (`nonmatchings/permsrc/perm.c`).

## Residual (12 instructions, two clusters)

1. **One scheduling rotation, 4 instructions.** ROM emits `[lui tod, lw tod, sll n<<8, sll m<<2]`;
   this build emits `[sll m<<2, lui tod, lw tod, sll n<<8]`. Tried and rejected: `tod` in its own
   temp (30), `tod` first in the sum (36), `m` pre-shifted (52), `do {} while (0)` around the
   address statement (34), a block break after `m` (58), `sky_time_of_day_idx` in subscript form
   (70).
2. **Four spill-slot pair swaps, 8 instructions.** The `Gfx*` frame slots run `0x2C, 0x3C, 0x34,
   0x54, 0x4C` in the ROM against `0x2C, 0x34, 0x3C, 0x4C, 0x54` here -- adjacent pairs inverted.
   `reload1.c` assigns slots in ascending pseudo number, and the pseudos are the `Gfx *_g` temps
   from `gDPNoParam` / `gSPSetOtherMode`, which expand identically on both sides, so the source-order
   explanation does not hold. Declaration-order changes do not move it (both variants 24).

A second permuter run from the 24-line base plateaued at score 385 over 4100 iterations with no
improvement, so neither cluster is permuter-reachable from this shape.

## Working body (634/634, best known form, cmpfn diff 24)

extern s32 sky_time_of_day_idx;
extern f32 D_800C5F24[];
extern f32 D_800C5F2C[];
extern f32 D_800C691C;
extern u8 D_800C6014[];
extern u32 D_800FE3D4;
extern s32 D_801B557C;
extern s32 func_80051FCC(void);

typedef struct {
  u8 prim_r;
  u8 prim_g;
  u8 prim_b;
  u8 env_r;
  u8 env_g;
  u8 env_b;
  u8 unk_06[2];
  s32 radius;
  u8 unk_0C[4];
  f32 t;
} FlarePoint;

extern FlarePoint D_800C6920[];

void func_8008D3F4(Gfx** gfxp) {
  Gfx* gfx;
  u8* e;
  u8* q;
  f32 dx;
  f32 dy;
  f32 s;
  f32 px;
  f32 py;
  s32 n;
  s32 m;
  s32 i;
  s32 w;
  s32 d;

  gfx = *gfxp;
  n = func_80051FCC();
  m = putter_mode_flag;

  gDPPipeSync(gfx++);
  gDPPipeSync(gfx++);
  gDPSetCycleType(gfx++, G_CYC_1CYCLE);
  do {
    gDPPipeSync(gfx++);
  } while (0);

  q = D_800C6014 + (((m << 2) + sky_time_of_day_idx) << 5);
  e = (u8*)((n << 8) + (u32)q);
  if (e[0x11] == 0) {
    return;
  }

  if (D_800C5F24[0] <= 16.0f) {
    return;
  }
  if (304.0f <= D_800C5F24[0]) {
    return;
  }
  if (D_800C5F2C[0] <= 16.0f) {
    return;
  }
  if (224.0f <= D_800C5F2C[0]) {
    return;
  }
  if (D_800C5F2C[0] < -64.0f) {
    return;
  }
  if (360.0f < D_800C5F2C[0]) {
    return;
  }
  if (D_800C5F24[0] < -120.0f) {
    return;
  }
  if (440.0f < D_800C5F24[0]) {
    return;
  }
  if (D_801B557C == 1) {
    return;
  }

  dx = 320.0f - D_800C5F24[0];
  if (160.0f < dx) {
    dx = 320.0f - dx;
  }
  dy = 240.0f - D_800C5F2C[0];
  if (96.0f < dy) {
    dy = 240.0f - dy;
  }
  s = (dx + dy + 16.0f) * D_800C691C;
  if (s < 8.0f) {
    return;
  }
  if (*(f32*)(*(u32*)(e + 0x14) + 0x18) < s) {
    s = *(f32*)(*(u32*)(e + 0x14) + 0x18);
  }

  gDPPipeSync(gfx++);
  gDPPipeSync(gfx++);
  gDPSetTexturePersp(gfx++, G_TP_NONE);
  gDPPipeSync(gfx++);
  gDPSetTextureLUT(gfx++, G_TT_NONE);
  gDPPipeSync(gfx++);
  gDPSetAlphaCompare(gfx++, G_AC_THRESHOLD);
  gDPSetBlendColor(gfx++, 255, 255, 255, 1);
  gDPPipeSync(gfx++);
  gDPPipeSync(gfx++);
  gDPSetCycleType(gfx++, G_CYC_1CYCLE);
  gDPPipeSync(gfx++);
  gDPSetRenderMode(gfx++, G_RM_CLD_SURF, G_RM_CLD_SURF2);
  gDPSetCombineLERP(gfx++, PRIMITIVE, ENVIRONMENT, TEXEL0, ENVIRONMENT, PRIMITIVE, 0, TEXEL0, 0,
                    PRIMITIVE, ENVIRONMENT, TEXEL0, ENVIRONMENT, PRIMITIVE, 0, TEXEL0, 0);
  gSPTexture(gfx++, 0x8000, 0x8000, 0, G_TX_RENDERTILE, G_ON);
  gDPPipeSync(gfx++);
  gDPSetTextureFilter(gfx++, G_TF_BILERP);
  gDPPipeSync(gfx++);
  gDPSetAlphaDither(gfx++, G_AD_PATTERN);
  gDPPipeSync(gfx++);
  gDPSetColorDither(gfx++, G_CD_MAGICSQ);
  gDPLoadTextureBlock(gfx++, D_800FE3D4 & ~7, G_IM_FMT_I, G_IM_SIZ_8b, 64, 64, 0, G_TX_MIRROR,
                      G_TX_MIRROR, 6, 6, G_TX_NOLOD, G_TX_NOLOD);

  for (i = 0; i != 8; i++) {
    px = D_800C5F24[0] + (160.0f - D_800C5F24[0]) * D_800C6920[i].t;
    py = D_800C5F2C[0] + (96.0f - D_800C5F2C[0]) * D_800C6920[i].t;
    gDPPipeSync(gfx++);
    gDPSetPrimColor(gfx++, 0, 0, D_800C6920[i].prim_r, D_800C6920[i].prim_g, D_800C6920[i].prim_b,
                    (u32)s);
    gDPSetEnvColor(gfx++, D_800C6920[i].env_r, D_800C6920[i].env_g, D_800C6920[i].env_b, 255);
    w = (s32)((f32)D_800C6920[i].radius * (s + 16.0f) * (1.0f / 128.0f));
    d = 0x10000 / w;
    gSPScisTextureRectangle(gfx++, ((s32)(px - (f32)w)) << 2, ((s32)(py - (f32)w)) << 2,
                            ((s32)(px + (f32)w)) << 2, ((s32)(py + (f32)w)) << 2, G_TX_RENDERTILE,
                            0, 0, d, d);
  }

  gDPPipeSync(gfx++);
  gDPSetAlphaDither(gfx++, G_AD_PATTERN);
  gDPPipeSync(gfx++);
  gDPSetColorDither(gfx++, G_CD_DISABLE);
  gDPPipeSync(gfx++);
  *gfxp = gfx;
}
