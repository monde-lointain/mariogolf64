`src/main/func_80071370.c`, 276B, 2-jal. Global-gated (`D_80105118[]`) sprite-draw loop; per glyph

## Sole residual: str<->i biv register swap ($s2/$s3)
```
        TARGET              MINE
51584:  move s3,zero (i=0)  move s3,a3 (str)     <- swap
515ac:  lbu  a0,0(s2) (str) lbu  a0,0(s3) (str)
515b0:  addiu s2,s2,1       addiu s3,s3,1
515b8:  addiu s3,s3,1 (i++) addiu s2,s2,1 (i++)
```

Target: `str`→$s2, `i`→$s3. Mine: reversed. Everything else (s0=xbase, s1=(xbase<<2)+0x40 giv,
s4=ybase, s5=0x400, s6=col, s7=pgfx) identical. 8 s-regs in both (no extra spill).

## Root cause (TERMINAL — gcc-2.7.2 global.c, sched_dive fan-out, 15 ablations)
`global.c allocno_compare` (587-607): priority = `floor_log2(n_refs)*n_refs / live_length`. Measured
(.lreg): str (pseudo 75) 7 refs / live_length 35 → 0.40; i (pseudo 77) 7 refs / 25 → 0.56. i higher →
allocated first → i=$s2 (lower), str=$s3. Target needs `live_length(str) <= live_length(i)`.
- ROOT of the gap: `str` is a PARAMETER, so gcc copies it to a callee-saved pseudo at function ENTRY
  (assign_parms), giving it a ~10-insn-longer range (the entry→guard bridge) than `i` (init'd inside
  the `if`). The target instead materializes `str`'s biv-init in the loop PREHEADER (`move s2,a3` at
  515a0, after the guard) — a short range — and puts `i=0` before the guard (long range). Every
  hand-source deferral of str's copy needs a 9th allocno (extra callee-saved) → doesn't match the
  target's 8 s-regs.

## Levers tried, none flip it (semantics-preserving)
i=0 hoist (before guard / at entry: i max ~30, str stays 35); i=0 before/after col; guard `[i]` vs
`[0]` (folds same); `str++` extracted to a standalone `u8 ch=*str++`; for-loop; char-split temp;
`str[i]` array-index (str stops being a biv → falls to $a3, breaks structure); local `p=str` deferral
(needs 9th reg). The ONLY flip found: adding an 8th `str` ref (e.g. `str[0]` in the guard) bumps
`floor_log2` 2→3 → pri(str) 0.69 > i — but that is a SEMANTICS CHANGE (extra load+branch), invalid.
No missing source str-ref (asm has exactly one `*str++`).

## Verdict
Terminal regalloc allocno-priority coin, param-entry-copy driven. Permuter is a theoretical fit
(perturbs live_lengths via temp insertion) but the live_length gap (35 vs 25) is robust, and project
precedent = ~0 permuter cracks on pure allocno swaps (S224/S233/CE88 below-gate not-attempted). ~96%,
below the 0.97 permuter gate. Carried. Re-attempt only via decomp-permuter as a low-EV escalation, or
if a future callee-signature/structural insight shortens str's live range without an extra reg.
