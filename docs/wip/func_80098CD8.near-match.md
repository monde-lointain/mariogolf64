# func_80098CD8 near-match (S221 carry)

`src/main/func_80095A10.c`, 38 instr, 0-jal/0-fp. `#local-alloc-qty-permutation`.

## Function
Byte-mapper: for each of `count` input bytes, `b = src[i]`; if `b >= 28` return
-1; else `dst[i] = *D_800C73F0[(b + i) % 28]` (signed `%28` magic-multiply into a
`u8 *[]` pointer table, deref first byte). Returns 0.

## Source (structurally exact, root-caused)
```c
s32 func_80098CD8(u8 *src, u8 *dst, s32 count) {
  s32 i;
  for (i = 0; i < count; i++) {
    u8 b = *src++;
    if (b >= 28) return -1;
    *dst++ = *D_800C73F0[(b + i) % 28];
  }
  return 0;
}
```
extern: `u8 *D_800C73F0[];`

## Verdict: every instruction present; two coupled residual diffs
Compiler-source fan-out (gcc-2.7.2 expmed.c/sched.c/local-alloc.c) confirmed the
idiom exactly (signed /28 magic 0x92492493, post_shift 4, add-back + `sra 31`
@expmed.c:3058; `×28` synth_mult `(q<<3-q)<<2`; `u8 *[]` table). The body compiles
to all 38 target instrs; the only diffs:

1. **Pervasive register rotation**: target i=`t0`, src=`t1`, magic=`t2`, table=`t3`;
   build i=`a3`, src=`t0`, magic=`t1`, table=`t2` (uniform shift-by-one).
2. **Store/increment schedule swap**: target emits `sb; dst++; i++; slt; bnez;
   src++(delay)` (store FIRST); build emits `src++; i++; sb; slt; bnez; dst++(delay)`
   (increments hoisted above store).

## Root cause
Pre-reload scheduler (sched.c, active at -O2) freely places `src++` and `i++`:
`dst++` is WAR-pinned after the store (store reads `a1`=dst), but `src++`/`i++` have
no anti-dep to the store, so the scheduler floats them above it. That schedule
choice flips i's live range, which flips the local-alloc coloring (the rotation).
The two diffs are one root: the scheduler tie-break. fn1 has TWO pointer givs
(src++ AND dst++); the sibling func_80098D70 (byte-exact) has ONE giv + i-indexed
src, so its schedule/coloring settle correctly. The extra giv is decisive and is
not source-controllable (strength reduction always makes both stride-1 accesses
givs regardless of `src[i]` vs `*src++` source form — verified identical codegen).
