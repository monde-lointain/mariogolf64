# `func_800947A8` near-match (S301)

`src/main/func_8008D100.c`, 618 instructions, 0x9A8. Sky-panel snapshot emitter, sibling of the
banked `emit_snapshot_panel_grid_dl` in the same file.

## Status

**Exact instruction count (618/618), exact frame (-0x98), fully reconstructed semantics.** Not
banked. `cmpfn` diff is 404 lines (about 200 of 618 instructions differ), all downstream of one
`loop.c` movable-selection coin.

## What the function does

`n = D_800C5EE4`, early-out if `n <= 0`. Builds one modelview matrix from
`func_80065A1C(mf, angles, pos)` + `convert_and_pack_floats_to_fixed(mf, &D_800E4BD0[bank])` with
`angles[0] = 0`, `angles[1] = angles[2] = (f32)(D_800D1E50 - n * D_800D1E48)`,
`pos = {0, 0, -290.0f - (f32)(0xFF - n)}`. Then an 18-command DL preamble, a 4x5 textured-quad grid
(`gDPLoadTextureBlock` 64x32 RGBA16 + 4 `gSPModifyVertex(G_MWO_POINT_ST)` + `gSP2Triangles`), a
second 4x5 `gSP2Triangles`-only pass under `G_CC_SHADE`, a 24-vertex reload, a 3x5 pass with a
different ST layout, and `D_800C5EE4 -= 10`.

Vertex indices per cell are `k = j + row`, `k+6`, `k+7`, `k+1`, where `row`/`row1` are loop-carried
accumulators stepping by 6 per outer iteration, copied into per-outer temps (`base`, `base1`) at the
top of the outer body. Last column (`j == 4`) narrows the S coordinate from `0x40` to `0x2F`.

## The residual

Seven global (callee-saved) allocnos in the ROM:

| reg | ROM | this build |
| --- | --- | --- |

| `s4` | `0xE7000000` (PipeSync w0) | same |
| `s5` | `row1` | same |

| `s8` | `0xFD100000` (SetTextureImage w0) | same |

Six of seven match. The seventh is a `loop.c` movable-selection coin inside the loop-1 inner loop.
`gcc -dL` (`t.c.loop`, `Loop from 473 to 837: 115 real insns`) shows loop.c moves the first three
life-1 constant loads and then reports `move-insn savings 1 not desirable` for every later one:

```

Insn 506: regno 217 (life 1), move-insn savings 1  moved to 1680
Insn 521: regno 221 (life 1), move-insn savings 1  moved to 1682
Insn 525: regno 222 (life 1), move-insn savings 1 not desirable
...
Insn 574: regno 235 (life 100), move-insn savings 1  moved to 1684
Insn 663: regno 253 (life 31), move-insn savings 1  moved to 1686
```

The constant `4` is used by the inner `bne t1,<4>` and the outer `bne t8,<4>` (one shared pseudo in
both builds), but its def sits late in the inner body, so it loses the three-slot window to
`0xF5100000` from the `gDPSetTile` half of `gDPLoadTextureBlock`. The ROM hoists `4` and
re-materialises `0xF5100000` per iteration; this build does the reverse. Counts stay equal (one
instruction traded each way), which is why the body is 618/618 with a large register/scheduling
divergence in `in1` (31 mnemonic diffs) and `in3` (90).

## Levers tried, measured (cmpfn diff lines, lower is better)

| change | result |
| --- | --- |
| index expressions inline as `i * 6 + j + C` | 601 (no givs; loop.c combines them) |
| explicit `row`/`row1` accumulators + `row += 6` | 612 |
| explicit per-outer copies `base = row; base1 = row1;` | **618/618 exact count**, 474 |
| `t6 = base + 6; bl = j + t6;` (defeats fold's reassociation to `(j+6)+base`) | 474 -> operand order exact |
| split `row`/`row1` for loop 3 | 462 |
| split `row`/`row1` for loop 2 | 412 |
| split `base`/`base1` for loop 2 as well | 624 + frame spill (reverted) |
| move `mfp = mf;` down to the call site | 426 (whole FP prologue lands exactly) |
| swap `row1 = 1; row = 0;` init and increment order | row1 lands in `s5` |
| `do { base = row; } while (0)` (S290 ref-doubling: `row` 7 refs -> 8, priority 648 -> 1111) | **404**, `row` lands in `s3` |
| `w`-select moved before `gDPLoadTextureBlock` | `s6 = 4` lands, but the whole inner body reorders: 560 |
| `last = 4` shared variable for bound + test | 594-887 (cprop re-materialises it) |
| ternary `w = (j == 4) ? 0x2F : 0x40` | 626 |
| `do { if (j == 4) { w = 0x2F; } } while (0)` (second ref-doubling site) | **398**, best known |

The `do {} while (0)` ref-doubling lever and the `mfp` sink are both new confirmations of documented
levers. The `w`-select-first form is the only one that lands `s6 = 4`; it costs the inner-loop
emission order, so the crack needs the `4` def to move early in the RTL *without* moving the branch.

## Next actions

2. Or find a source form that puts the `4` def early in the inner body while leaving the `bne` late.
3. Do not price this leaf as fresh at the next gate: it is a characterised carry.
