# func_8005CF78 — CARRIED (large jtbl-dispatch 3-level loop; deferred, not a proven wall)

## Why carried
All-or-nothing: the function dispatches through a compiler jump table `jtbl_800D0A60`, which only exists
as source when the switch is written in C (gcc regenerates it). The rodata carve therefore CANNOT be
applied while the function is still `INCLUDE_ASM` (proved S265: carving `[0xABE90,...]` back to `0xABE60`
gives `undefined reference to jtbl_800D0A60` from the still-asm body). So the carve + the full C
reconstruction must land together in one shot; a partial/probe is not possible.

## Carve recipe (apply WITH the C body, not before)
`jtbl_800D0A60` is at ROM 0xABE60 / vram 0x800D0A60, 12 words (0xABE60..0xABE90), preceded by `.align 3`
(8-aligned start), immediately before the already-owned `[0xABE90, .rodata, main/func_80059BA0]`
(func_8005DAFC's jtbl_800D0A90, S264). Carve = extend that subseg back one line:
`- [0xABE90, .rodata, main/func_80059BA0]` -> `- [0xABE60, .rodata, main/func_80059BA0]`.
8-aligned both edges, only the 12-word table between them (clean per `docs/levers.md` (jtbl carve both edge 8align)).

## Expected difficulty
- The ~8 conditional single stores are `beql`+annulled `sw` = NORMAL gcc-2.7.2 codegen for
  `if (cond) *p = 1;` (NOT the S263 const-SELECT value-select wall — this stores, it does not select a
  value into a variable). Should reproduce from faithful `if`s.
- Real risk = regalloc/scheduling on an 88-instr 3-loop body + getting all the fixed base offsets
  (0x1FF8 / 0x21D8 / 0x3C / 0x40 / 0x76 strides 0xA0 / 0x2E0 / 0xB8) and the section/arr induction
  exactly. The many hard-reg temps (t0-t7 all live across the outer loop) suggest a caller-saved-heavy
  allocation the source must steer (declare loop-invariant bases as locals live across the loop).
- The switch default-sets-flag is a plain conditional store on the default arm; write it as
  `switch(sel){case 0:case 2:case 4:case 5:case 10:case 11: break; default: arr[k]=1;}`.

Not a proven wall — a tractable but LARGE classical reconstruction. Route to a dedicated crack slice
(seed asm-first, iterate on the base-offset struct form + the outer-loop invariant regalloc).
