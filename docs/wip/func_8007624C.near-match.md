# func_8007624C near-match (S246 carry)

`src/main/func_80071370.c` glyph-emitter family. Fully RE'd; residual is a raw-DL-word
regalloc/scheduling wall (S243 class). CARRIED.

## Semantics (100% reverse-engineered)
Two-pass drop-shadow glyph emitter.
`void func_8007624C(Gfx** cursor, s16 x, s16 y, u8* str, s32 color1, s32 color2, s32 flags)`
- Decomposes color1/color2 into their top-3 bytes via arithmetic `>> 24/16/8`, stored to two u8
  stack arrays at sp+0x10 (c1[0..2]) and sp+0x18 (c2[0..2]) via `sb`, re-read via `lbu`.
  The 8-byte spacing (0x10 vs 0x18) means each is an 8-byte slot (u8 c1[8]/c2[8] or padded).
- PASS 1 (dimmed shadow, offset +1,+1): emits gDPPipeSync, gDPSetEnvColor with
  `((c1[k]>>2)<<shift)|0xFF` RAW packing (NOT the gDP macro — the macro adds andi masks the ROM
  lacks), gDPSetPrimColor(m=0,l=0) with the same `>>2` quantization of c2. Then dispatches by flags:
  `if (flags&0x10) func_800747B0; else if (flags&0x80) func_80073C14; else func_80073F24` — each
  called `(&localGfx, (s16)(x+1), (s16)(y+1), str)`.
- PASS 2 (full colour, at x,y): emits gDPSetEnvColor + gDPSetPrimColor with FULL (no `>>2`) raw
  packing of c1/c2, same flag dispatch called `(&localGfx, x, y, str)`.
- FINAL: gDPPipeSync, then `*cursor = localGfx`.
- Sub-emitters take `(Gfx** dl, s16 x, s16 y, u8* str)` (coords truncated to s16 at every call site,
  so func_800747B0's real param type is s16 even though its banked definition uses s32 — matches
  incidentally). func_800747B0 is banked; func_80073C14/73F24 are INCLUDE_ASM.

## Residual wall
The DL commands are written via a FIXED base register (a2 = `gfx = *cursor`, offsets 0/8/0x10) while
a SEPARATE `localGfx` (sp+0x20) is post-incremented to gfx+1/+2/+3 (4 dead stores) and `&localGfx`
passed to the sub-emitters. Reproducing this fixed-base-write + incrementing-slot split, together
with keeping x/y in callee-saved s0/s1 (not staged through t0/t1) across the two dispatch rounds, is
the wall:
- `dl = &gfx[3]` (single localGfx store) compiles 7 instrs SHORT (166 vs 173) — misses the dead-store
  increments.
- `gfx = dl++` post-inc per command compiles 6 instrs LONG (179 vs 173) — x/y stage through t0/t1
  (extra moves) and the localGfx base lands in a3 not a2.
Both are pure register-allocation / store-giv scheduling divergences with the color/byte body already
byte-exact. This is the S243 raw-DL-word wall (post-inc-idiom store-giv + sched-order coin). Next
attempt: a compiler-source fan-out on the localGfx store-giv + x/y biv placement (global.c allocno
order for the two coord bivs across the call), or the permuter on the localGfx/coord live ranges.

## PO note
The quantized (`>>2`) color packing cannot use the high-level gDPSetEnvColor/gDPSetPrimColor macros
(they emit extra andi masks the ROM lacks); it needs raw `(byte>>2)<<shift|0xFF` packing. Only
gDPPipeSync maps cleanly to a macro here.
