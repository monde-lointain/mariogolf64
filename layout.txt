# The ROM's layout, in order, for tools/layout.py, which writes the linker
# scripts from it.
#
#   segment NAME ADDRESS   code and data that run at ADDRESS in RAM
#       PATH [KIND...]     an object to place, by its source's path
#       pad SIZE KIND      a gap of SIZE bytes among the sections of KIND
#   file PATH              a file that the ROM holds as it is
#
# A segment places its objects' code (text), then their data, read-only data
# (rodata) and bss, each in the order of the lines that list them. A line
# places the kinds that it names, all four if it names none, so an object
# whose sections go in another order is listed once for each. A line that
# names "common" places the object's common symbols; a segment with no such
# line places each object's after its bss. "matching" marks an object that
# only the original's layout links. A file's symbols are named after its
# path below assets/, such as text_glyphs_ROM_START for
# assets/text/glyphs.bin. '#' starts a comment.
